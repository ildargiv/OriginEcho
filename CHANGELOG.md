# Changelog

## Unreleased

- ExifTool is no longer stored in the repository: the build downloads the pinned version 13.59 and checks every file against `tools/exiftool.sha256`. The released exe and installer still include it.
- Releases carry `SHA256SUMS.txt`.
- Pull requests are built and smoke-tested on GitHub.
