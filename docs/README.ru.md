# OriginEcho

**Восстановление истории съёмки, потерянной после обработки фото нейросетью.**

Когда вы прогоняете фотографию через ИИ-генератор или редактор, готовый файл
обычно выходит **обнажённым**: марка и модель камеры, дата и время съёмки,
GPS-координаты, ISO, экспозиция и данные об объективе — всё стирается. Картинка
выглядит так же, но её история исчезла.

**OriginEcho** возвращает эту историю. Он переносит полные метаданные
оригинала на обработанное ИИ-фото — а при желании ещё и восстанавливает
формат оригинала и переименовывает результат.

## Что делает

| | |
|---|---|
| **Переносит EXIF** | камера, модель, дата/время, GPS, ISO, экспозиция, объектив, фокусное… |
| **Переносит XMP + IPTC** | подписи, автор, ключевые слова, рейтинг, история правок |
| **Переносит цветовой профиль** | ICC-профиль, чтобы цвета остались точными |
| **Восстанавливает формат** | обработанный файл конвертируется в формат оригинала (PNG → JPEG, WEBP → JPEG…) |
| **Переименовывает результат** | `имя_оригинала имя_обработанного.ext` |
| **Восстанавливает даты файлов** | даты «создания» и «изменения» как у оригинала |

## Зачем

ИИ-инструменты пересобирают файл с нуля и ничего не знают о метаданных
оригинала. OriginEcho берёт их из нетронутого оригинала и «прививает» к
обработанной копии — итоговое фото сохраняет своё происхождение.

## Быстрый старт

1. Дважды щёлкните **`OriginEcho.bat`** (Windows) — откроется окно программы.
2. В поле **ОРИГИНАЛ** укажите нетронутое фото (или папку с оригиналами).
3. В поле **ОБРАБОТАННЫЕ ФОТО** укажите результат работы ИИ (файл, несколько
   файлов или папку). Можно **перетащить** файлы мышкой прямо в поля.
4. Нажмите **ВЫПОЛНИТЬ ПЕРЕНОС**.

Результат появится рядом с обработанным файлом с именем
`<имя оригинала> <имя обработанного>.<расширение оригинала>`.

### Опции

- **Формат как у оригинала** — конвертировать в формат оригинала.
- **Имя: оригинал + копия** — переименовать в «оригинал + пробел + копия».
- **Удалить старый файл** — убрать исходную копию после успешного переноса.
- **Скопировать даты файлов** — перенести даты создания/изменения.

## Командная строка

```bash
python tools/copy_photo_metadata.py оригинал.jpg результат.jpg [ещё.jpg ...]
python tools/copy_photo_metadata.py --folder ПАПКА_ОРИГИНАЛОВ ПАПКА_ОБРАБОТАННЫХ
```

Флаги: `--no-icc`, `--no-dates`, `--no-convert`, `--no-rename`, `--keep-old`.

## Поддерживаемые форматы

Ввод/вывод: **JPEG, PNG, WEBP, TIFF**. HEIC поддерживается при установленном
`pillow-heif`.

## Примечания и качество

- Для **JPEG → JPEG** OriginEcho правит файл на уровне байтов, поэтому данные
  изображения сохраняются **без потерь** — без пересжатия.
- Конвертация между форматами (например PNG → JPEG) неизбежно перекодирует файл.
- Прозрачные PNG/WEBP при переводе в JPEG подкладываются на белый фон.
- PNG и WEBP ограниченно поддерживают некоторые поля EXIF (это ограничение
  форматов). Для полного сохранения лучше использовать JPEG.
- Полный перенос (XMP/IPTC) выполняет **exiftool** (в папке `tools/exiftool`);
  без него программа ограничивается EXIF + ICC.

## Требования

- Python 3.11+
- Pillow (при необходимости ставится автоматически)
- `tkinterdnd2` — перетаскивание мышью (необязательно)
- exiftool — полный XMP/IPTC (необязательно, в комплекте)
