# OriginEcho

**AI से फ़ोटो एडिटिंग के बाद खोई हुई शूटिंग इतिहास वापस लाएँ।**

जब आप किसी फ़ोटो को AI जनरेटर या एडिटर से गुज़ारते हैं, तो आउटपुट फ़ाइल
आम तौर पर **नंगी** आती है: कैमरा ब्रांड और मॉडल, शूट की तारीख़ और समय, GPS
निर्देशांक, ISO, एक्सपोज़र और लेंस की जानकारी — सब कुछ गायब। तस्वीर वैसी ही
दिखती है, पर उसकी कहानी खत्म हो जाती है।

**OriginEcho** वही कहानी वापस देता है। यह मूल फ़ोटो का पूरा मेटाडेटा AI-संपादित
इमेज पर कॉपी करता है, और चाहें तो फ़ाइल फ़ॉर्मैट भी वापस लाता है तथा परिणाम
का नाम बदल देता है।

---

## यह क्या करता है

| | |
|---|---|
| **EXIF कॉपी करता है** | कैमरा, मॉडल, तारीख़/समय, GPS, ISO, एक्सपोज़र, लेंस, फोकल लेंथ… |
| **XMP + IPTC कॉपी करता है** | कैप्शन, लेखक, कीवर्ड, रेटिंग, एडिट इतिहास |
| **रंग प्रोफ़ाइल कॉपी करता है** | ICC प्रोफ़ाइल, ताकि रंग सटीक रहें |
| **फ़ॉर्मैट वापस लाता है** | AI परिणाम को मूल के फ़ॉर्मैट में बदलता है (PNG → JPEG, WEBP → JPEG…) |
| **परिणाम का नाम बदलता है** | `मूल-नाम संपादित-नाम.ext` |
| **फ़ाइल तिथियाँ वापस लाता है** | बनाए/बदले की तारीख़ मूल जैसी |

## क्यों

AI टूल फ़ाइल को शून्य से बनाते हैं और उन्हें मूल फ़ोटो के मेटाडेटा की जानकारी
नहीं होती। OriginEcho उन्हें अछूती मूल फ़ाइल से पढ़कर संपादित कॉपी पर लगा देता है,
जिससे तैयार फ़ोटो अपनी वास्तविकता और अपना स्रोत बनाए रखता है।

## त्वरित शुरुआत

1. **`OriginEcho.bat`** पर डबल-क्लिक करें (Windows) — प्रोग्राम खुलेगा।
2. **मूल फ़ोटो** में अछूती फ़ोटो (या मूल फ़ोटो का फ़ोल्डर) चुनें।
3. **संपादित फ़ोटो** में AI का परिणाम चुनें (एक फ़ाइल, कई फ़ाइलें, या फ़ोल्डर)।
   आप फ़ाइलें सीधे खानों में **खींचकर छोड़** भी सकते हैं।
4. **ट्रांसफ़र शुरू करें** दबाएँ।

परिणाम संपादित फ़ाइल के पास बनता है, नाम
`<मूल नाम> <संपादित नाम>.<मूल एक्सटेंशन>`।

### विकल्प

- **मूल जैसा फ़ॉर्मैट** — मूल के फ़ॉर्मैट में बदलें।
- **नाम: मूल + कॉपी** — «मूल + स्पेस + कॉपी» नाम बनाएँ।
- **पुरानी फ़ाइल हटाएँ** — नाम बदलने के बाद पुरानी कॉपी हटा दें।
- **फ़ाइल तिथियाँ कॉपी करें** — बनाए/बदले की तिथियाँ लगाएँ।

## कमांड लाइन

```bash
python tools/copy_photo_metadata.py original.jpg edited.jpg [aur.jpg ...]
python tools/copy_photo_metadata.py --folder ORIGINALS FOLDER EDITED
```

फ़्लैग: `--no-icc`, `--no-dates`, `--no-convert`, `--no-rename`, `--keep-old`.

## समर्थित फ़ाइल फ़ॉर्मैट

इनपुट/आउटपुट: **JPEG, PNG, WEBP, TIFF**। `pillow-heif` इंस्टॉल होने पर HEIC भी
समर्थित है।

## नोट्स और गुणवत्ता

- **JPEG → JPEG** में OriginEcho फ़ाइल को बाइट-स्तर पर संपादित करता है, इसलिए
  चित्र डेटा **बिना क्षति** सुरक्षित रहता है — कोई दोबारा कंप्रेशन नहीं।
- फ़ॉर्मैट बदलने पर (जैसे PNG → JPEG) चित्र दोबारा एन्कोड होता है।
- पारदर्शी PNG/WEBP को JPEG में बदलते समय सफ़ेद पृष्ठभूमि पर रखा जाता है।
- PNG और WEBP कुछ EXIF फ़ील्ड केवल सीमित रूप से समर्थन करते हैं (यह फ़ॉर्मैट की
  सीमा है)। सब कुछ सुरक्षित रखने के लिए JPEG बेहतर है।
- पूरा स्थानांतरण (XMP/IPTC) **exiftool** करता है (`tools/exiftool`); उसके बिना
  प्रोग्राम केवल EXIF + ICC तक सीमित रहता है।

- exiftool — पूरा XMP/IPTC (वैकल्पिक, शामिल)
